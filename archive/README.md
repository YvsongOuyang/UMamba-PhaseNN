# Archive

This directory keeps legacy scripts, notebooks, logs, and reference outputs that
are not part of the current training entrypoint.

- `legacy_scripts/`: older or duplicated training/data-loader scripts kept for reference.
- `legacy_notebooks/`: exploratory notebooks and earlier notebook-based training runs.
- `logs/`: historical local training logs.
- `reference_outputs/`: snapshots and figures kept as references.

Current training is driven from the repository root by `lcrc_run_interactive.sh`
and `oyys_lcrc_train_singleGPU.py`.
