# 本地验收（2026-09-11）

执行环境：Windows、Python 3.10、RTX 5070、torch 2.11.0+cu128、torchvision 0.26.0+cu128、NumPy 2.2.6；其它包版本按 requirements。未在用户服务器上运行，不能将本地验收称为 Linux/GPU 全组合测试。

已通过：

- 作者 model.py、complexNN.py、untils.py 的 SHA256 与原始快照一致。
- 默认 12000/1500/1500 样本 ID 与此前原始代码运行保存的划分逐项一致，无交集。
- 6 项契约检查：主文划分、生成器与标签的傅里叶一致性、振幅输入单位、非有限梯度拒绝、有限参数但 Adam 动量为 Inf 时拒绝、单 batch 和不等 batch 的加权 MAE。
- 生成 2 个 seed（392 个原始样本），全部前向/标签检查通过，最大振幅 χ² 为 `3.374399179912152e-15`。这是数据一致性误差，不是模型预测误差。
- 用前 200 个样本划分 160/20/20，GPU 训练 2 轮，退出后读取 last.pt 续至第 3 轮；学习率从 `0.001` 按 epoch 单调下降，状态、优化器和调度器可恢复。
- 第 3 轮 best.pt 在上述 20 个测试样本上评估并写出 NPZ/JSON：MAE `0.2825390769`，零预测基线 `0.2688341339`，振幅 χ² `0.9748606050`，所有输出有限。这只验收执行链路，预测质量尚差。

## 尚未解决的实验效果

另以该小数据集的训练集前 8 个样本进行 500 次更新（每轮 1 batch），第 100 轮后测试了断点恢复。整个过程未触发非有限检查，但第 500 轮在这 8 个样本上的 MAE 为 `0.2715201378`，零预测基线 `0.2731195688`，预测振幅均值仅为真实值的约 `4.795%`；最佳 MAE 为 `0.2710056901`。因此这项**拟合能力诊断没有达到充分拟合标准，仍接近零预测**。

已修复的数值/数据错误不等于已经解决重建效果问题。全量训练每 epoch 有 188 次更新，8 样本诊断每 epoch 只有 1 次更新，不能由此直接推断全量 500 epoch 的终态；也不能将此诊断称作复现成功。当前没有重新跑全量 500 轮。

继续实验时应先预跑、保留全零 MAE 和振幅比，最终以独立测试集的重建效果判断。衍射振幅本身有全局相位等不可辨识性，而作者使用固定复数标签的直接 L1 目标；这可能需要单独研究，但本提交不以未经验证的相位对齐/新损失替换作者方法。

本提交不包含旧发散 checkpoint、试跑权重、数据集或本机依赖目录。
